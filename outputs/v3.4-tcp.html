TCP 慢启动与拥塞控制

慢启动其实涨得很快：每个 ACK 让拥塞窗口 cwnd 加 1 个 MSS，所以每个往返时间（RTT）cwnd 约翻倍。cwnd 到达阈值 ssthresh 后改为每个 RTT 只加 1 个 MSS。发生丢包时，ssthresh 降到在途数据的一半；超时让 cwnd 回到 1，三个重复 ACK 只让 cwnd 降到新的 ssthresh。

阅读路径：先看「概览」；想会推算就走「机制」里的逐步播放和参数模型；需要细节时展开「深入」。本页按 Reno/NewReno 语义（RFC 5681），按 RTT 粒度简化，见模型边界。

概览两个窗口、两个阶段、两种丢包反应

发送方一次最多能有 min(cwnd, rwnd) 的数据在途。rwnd 是接收方通告的窗口；cwnd 是发送方对“网络还能装多少”的估计。网络不会直接告诉发送方容量，发送方只能从 ACK（数据到了）和丢包（装不下了）推断。

慢启动

条件：cwnd < ssthresh。

每个 ACK：cwnd += 1 MSS → 每 RTT 约 ×2。

作用：快速找到大致容量。

拥塞避免

条件：cwnd > ssthresh（相等时两者都可）。

每个 ACK：cwnd += MSS²/cwnd → 每 RTT 约 +1 MSS。

作用：在上限附近小心试探。

超时（RTO）

ssthresh = max(在途/2, 2 MSS)

cwnd = 1 MSS，重新慢启动。

含义：连 ACK 都停了，按严重拥塞处理。

三个重复 ACK

ssthresh = max(在途/2, 2 MSS)

快速恢复结束后 cwnd = ssthresh，继续拥塞避免。

含义：后面的包还在到达，只丢了个别包。

“慢”指什么：相对于“一开始就按 rwnd 全速发”而言是慢；相对于拥塞避免的线性增长，它是指数增长。

机制为什么“每个 ACK 加 1”等于“每 RTT 翻倍”

逐步播放一次慢启动。示意：cwnd 从 2 MSS 开始，忽略延迟 ACK。每一步只发生一个事件。

先预测，再验证

IW = 10，ssthresh = 20，网络不丢包。第 4 个 RTT 发多少个 MSS？

22。第 1 个 RTT 发 10；第 2 个翻倍到 20，到达 ssthresh；之后拥塞避免，每 RTT +1：第 3 个 21，第 4 个 22。

参数模型：改参数，看 cwnd 曲线

“网络容量”是一个简化：某个 RTT 发出的数据超过它就丢包（瓶颈队列溢出）。改变丢包反应、容量或初始 ssthresh，看锯齿怎样变化。

深入规则原文与实现差异

RFC 5681 的精确规则
  • 慢启动每个确认新数据的 ACK：cwnd += min(N, SMSS)，N 是该 ACK 新确认的字节数（式 2）。
  • 拥塞避免每个 ACK：cwnd += SMSS*SMSS/cwnd（式 3），约每 RTT +1 SMSS。
  • cwnd 与 ssthresh 相等时，发送方可以用任一算法。
  • 丢包后 ssthresh = max(FlightSize/2, 2*SMSS)（式 4）。
  • 超时：cwnd 不超过丢失窗口 LW = 1 个满尺寸段。
  • 快速重传/恢复：第 3 个重复 ACK 时重传，cwnd = ssthresh + 3*SMSS；之后每个重复 ACK +1 SMSS（“膨胀”）；确认新数据的 ACK 到达时 cwnd 设回 ssthresh（“收缩”）。
初始窗口为什么是 10

RFC 6928（实验性）把初始窗口上限提高到 min(10*MSS, max(2*MSS, 14600)) 字节。MSS = 1460 时正好 10 段。较早的 RFC 3390 上限约为 4 段。具体系统的取值可能不同。

CUBIC 和 BBR 有什么不同

CUBIC（RFC 9438）保留慢启动和“丢包即降窗”的骨架，但拥塞避免阶段按三次函数增长，丢包时乘以 β = 0.7（Reno 是 0.5）。Linux 默认使用 CUBIC。BBR 以测得的带宽和 RTT 为主要信号，不以丢包为主，本页模型不适用。

模型边界：这个模拟器不代表什么
  • 按 RTT 粒度计算：慢启动每 RTT 翻倍，到 ssthresh 时截断为 ssthresh；真实 TCP 按 ACK 增长，可能略超过 ssthresh。
  • “容量”是硬阈值：超过即在该 RTT 检测到丢包，下一 RTT 生效。真实网络的队列、RED/ECN、多流竞争都没有建模。
  • FlightSize 取本轮发出量；快速恢复期间的膨胀被折叠为“下一 RTT cwnd = ssthresh”。
  • 没有 rwnd 限制、延迟 ACK、SACK、RTO 退避。数字是模型输出，不是实测。
